MPD MUSIC STUDIO WORLD V25 CHANGELOG
Created: 2026-11-23

1. 기타 구성 복원
- V24에서 일렉트릭 기타로 대체되며 빠졌던 원래 어쿠스틱 기타를 세 번째 악기로 복원했습니다.
- 베이스 기타와 일렉트릭 기타의 기존 위치 및 Spotify 트랙 연결은 유지합니다.

2. 정면 바다/좌우 숲 연결 구조
- 정면 해안 사진을 기존 평면에서 원통 곡면으로 변경했습니다.
- 정면 해안 원통과 숲 원통의 반경(224) 및 중심 높이를 동일하게 맞추고, 정면 해안 구간이 숲 구간과 양쪽에서 겹치도록 해 방사 방향 단차를 제거합니다.
- 원본 정면 해안 사진은 교체하지 않았습니다.
- 정면 해안 원본 사진의 상단 하늘만 잘라 360도 하늘 쉘로 사용하여 위쪽 빈 공간을 같은 하늘로 메웁니다.
- 숲 텍스처의 미세 선명도와 실제 3D 나무 크기를 보수적으로 조정합니다.

3. 카메라 및 수중 탐색
- 육지 카메라의 기본 위치를 캐릭터 뒤쪽 3인칭 시점으로 설정합니다.
- 육지에서 위로 올리는 시야는 수평선까지 제한하고, 아래쪽 시야는 기존처럼 유지합니다.
- 수중 카메라는 캐릭터 뒤쪽 3인칭으로 시작하며, 상하/좌우 회전과 줌 범위를 넓힙니다.
- 수중 캐릭터 이동 중 카메라와 궤도 목표점을 함께 이동시켜 캐릭터가 화면 안에 유지되도록 합니다.

4. 모바일 UI
- 기존 V23 모바일 CSS에서 사용하던 클래스가 실제 JSX에 연결되도록 상단 헤더/브랜드/메뉴, 채팅, 방명록, 음악 플레이어에 클래스를 연결합니다.
- Global Chat 칩을 로고 바로 아래에 더 얇고 작게 배치합니다.
- 모바일 배경 음악 및 Spotify 플레이어를 축소하여 조이스틱/음소거 조작 영역과 겹침을 줄입니다.

5. 안전 및 배포
- 본 패치는 프로젝트의 소스 코드만 수정하며 .env.local, Supabase 데이터, Vercel 환경변수는 수정하지 않습니다.
- 실행 스크립트는 백업, TypeScript 검사, 프로덕션 빌드, GitHub main Push, Vercel Production 배포 및 mpd-music.vercel.app alias 연결을 수행합니다.
- 빌드 전 실패 시 패치 파일을 자동 복구하고, 배포 단계 실패 시 빌드된 코드를 유지합니다.
