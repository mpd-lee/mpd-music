MPD MUSIC STUDIO WORLD V41 변경 내역
====================================
기준 소스: 사용자가 제공한 MPD_MUSIC_STUDIO_LATEST_SOURCE.zip

1) 지상 하늘 / 숲 경계
- 기존 V29 sky-canopy 360 텍스처를 유지합니다.
- 이미지 생성 없이 런타임 CanvasTexture의 세로 위도 매핑만 부드럽게 보정합니다.
- 하단의 구름층을 시야 수평선 쪽으로 이동시켜 캐노피 위의 넓은 단색 하늘을 줄입니다.
- 숲 원통, 정면 해안 배경, 숲 색상/기하 구조는 변경하지 않습니다.

2) 수중 배경
- 기존 V32 자연 산호초 파노라마를 유지합니다.
- 별도 광선, 블러, 수중 사진 합성은 추가하지 않습니다.
- 이전 회전값이 원본 파노라마 내부 이음부를 시야 앞쪽으로 가져오는 문제를 피하도록 원본 회전값(0)으로 복귀합니다.

3) 수중 이동
- 수중 위치 이동의 단일 소유자를 Avatar.useFrame으로 통합합니다.
- 키보드 / 조이스틱 / 상승·하강 입력이 같은 moveVectorRef를 통해 실제 아바타 위치를 갱신합니다.
- 카메라와 OrbitControls target이 아바타 이동량을 함께 따라갑니다.
- 카메라 기준 좌우 벡터의 외적 순서를 수정해 수평 입력 방향을 화면 방향과 일치시킵니다.
- 클릭/터치 목적지 이동을 3D waypoint로 처리합니다.
- PC용 상승/하강 버튼을 실제 JSX에 추가합니다. 기존 CSS 스타일을 재사용합니다.
- 모바일 조이스틱과 기존 모바일 상승/하강 버튼은 그대로 둡니다.

4) 줌 / 아바타 크기
- 수중 기본 FOV를 야외보다 소폭 넓게 사용해 원경을 약간 더 넓게 보입니다.
- 아바타 스케일은 야외 FOV 대비 투영 비율로 보정합니다.
- 휠과 두 손가락 핀치의 FOV 줌으로 캐릭터와 배경이 함께 확대/축소됩니다.

5) UI
- 기존 채팅, 방명록, SCUBA HUD, 상단 메뉴의 크기/위치는 변경하지 않습니다.
- 요청된 음악 플레이어와 접힌 음표 버튼만 아래쪽 이동 안내와 겹치지 않도록 약간 위로 올립니다.

중요
- 전체 TypeScript 검사와 Next.js 빌드는 설치 대상 PC에서 실행 스크립트가 진행합니다.
- 이 패키지 작성 환경에는 프로젝트 node_modules가 없으므로 전체 프로덕션 빌드를 여기서 실행했다고 주장하지 않습니다.
- 기존 .env / .env.local 파일을 읽거나 덮어쓰지 않습니다.
