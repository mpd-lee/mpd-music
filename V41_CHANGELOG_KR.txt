MPD MUSIC STUDIO WORLD V41 변경 기록
====================================

이번 수정은 사용자가 제공한 최신 MPD_MUSIC_STUDIO_LATEST_SOURCE.zip을 기준으로 했으며, UI 창/패널의 크기·위치·CSS는 수정하지 않습니다.

1. 야외 하늘
- 이전 V32 하늘 이미지의 넓은 단색 파란 띠가 보이는 문제를 줄이기 위해 기존 V40 구름 파노라마의 구름 밀도가 높은 수직 구간을 재매핑한 V41 2:1 텍스처를 추가했습니다.
- 천정 방향 오프셋을 0으로 돌려 인위적인 기울기로 빈 하늘이 커지는 현상을 방지합니다.
- 숲, 해안 원통, 오브젝트 배치는 수정하지 않습니다.

2. 수중 배경
- 기존 V32 산호초 파노라마를 유지합니다.
- 좌우 늘어진 가장자리만 기존 방식으로 크롭하고, 끝단 이음부만 좁게 블렌딩합니다.
- 수중 배경 yaw를 180도 회전하던 설정을 제거해 정면에 수직 띠가 생길 가능성을 줄였습니다.
- 인공 광선, 중앙 블러, 대형 마스크를 추가하지 않습니다.

3. 수중 이동
- 수중 위치 이동의 단일 소유자를 UnderwaterMovementController로 통합합니다.
- Avatar 프레임 루프는 수영 자세만 애니메이션하고, 수중 캐릭터 위치/카메라를 중복 이동하지 않습니다.
- PlayerControls의 공유 ref 입력을 수중 컨트롤러가 직접 읽습니다.
- 키보드/WASD, 조이스틱, 상승/하강 버튼은 동일 입력 ref를 사용합니다.
- 클릭/터치 목적지는 300~1,200m로 잡아 이동 반응을 바로 볼 수 있게 했으며, 반복 클릭으로 먼 거리까지 탐험할 수 있습니다.
- 수평 이동 경계는 기존 100km x 100km, 수심 경계는 최대 8,000m를 유지합니다.
- 카메라와 OrbitControls target을 동일한 월드 이동량만큼 이동시켜 3인칭 추적을 유지합니다.
- OrbitControls.update()를 이동 루프에서 중복 호출하지 않아 카메라가 되돌아가는 현상을 방지합니다.

4. 줌/원근감
- 야외와 동일한 카메라 거리/OrbitControls 줌 범위를 사용합니다.
- 수중 FOV만 소폭 넓혀 배경을 약간 멀게 보이게 하고 캐릭터 크기는 접선 비율로 보정합니다.
- 기존 수중 주변 산호 지형의 미세 축소를 유지합니다.

5. 보존
- app/globals.css, chat-panel.tsx, studio-app.tsx 등 UI 레이아웃 파일은 패치하지 않습니다.
- 환경 파일(.env*)을 읽거나 덮어쓰지 않습니다.
- 실패 시 V41이 수정한 파일만 설치 전 백업으로 복원합니다.

검증 범위
- TypeScript/TSX 5개 파일을 TypeScript 5.8.3 transpile parser로 구문 검사했습니다.
- 현재 작업 환경에는 프로젝트 node_modules가 없고 npm 레지스트리 연결도 불안정하여 전체 의존성 타입 검사와 Next.js 빌드는 이 환경에서 실행하지 못했습니다.
- 설치 스크립트가 사용자 PC에서 전체 TypeScript 검사와 Next.js 프로덕션 빌드를 실행하며, 둘 다 통과한 경우에만 GitHub push와 Vercel Production 배포를 진행합니다.
- 실제 브라우저의 클릭/터치/조이스틱/상승·하강/줌은 배포 후 기기에서 반드시 확인해야 합니다.
