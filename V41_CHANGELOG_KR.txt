MPD MUSIC STUDIO WORLD V41
==========================

이번 패치는 2026-11-28 사용자가 제공한 최신 MPD_MUSIC_STUDIO_LATEST_SOURCE.zip의 코드 구조를 기준으로 작성했습니다.

1. 하늘
- 기존 V43/V39 파노라마의 넓은 무구름 상단 영역을 줄인 V44 파노라마를 추가했습니다.
- 기존 360도 회전 방향과 수평선 구조는 유지하고, 상단 하늘에 구름이 더 일찍 나타나도록 수직 구도를 재구성했습니다.
- outdoor.tsx가 V44 데스크톱/모바일 텍스처를 읽도록 변경했습니다.

2. 수중 배경
- 기존 V32 자연 산호초 사진을 유지합니다.
- 중앙 블러/광선 효과를 새로 추가하지 않습니다.
- 배경 회전각을 바꿔 기존 사진에서 동굴/산호 경계가 정면 중앙을 가로지르지 않도록 방향을 조정했습니다.
- 배경 이미지 반복률을 1.08/1.04로 미세 조정해 수중 지형이 조금 더 멀리 보이도록 합니다.

3. 수중 이동 입력
- StudioScene에 수중 전용 네이티브 입력 안전 경로를 추가했습니다.
- 키보드 WASD/방향키/Space/Shift, 조이스틱 pointer 입력, 상승/하강 버튼 입력을 window capture 단계에서 직접 읽어 Avatar가 읽는 동일한 moveVectorRef에 씁니다.
- 기존 PlayerControls 이벤트 경로는 유지해 이중 입력 경로가 아니라 동일한 벡터 값을 갱신하도록 했습니다.
- Avatar는 ref로 초기 위치를 한 번만 설정하고 매 프레임 위치를 직접 갱신합니다. JSX position prop이 이동 중 이전 스폰 위치를 다시 적용하지 않도록 합니다.
- 수중 클릭 목적지 이동, 카메라 추적, X/Z 경계와 수심 제한은 기존 구현을 유지합니다.

4. UI
- 전역 창 배치, 채팅, 방명록, 플레이어 크기 및 위치는 변경하지 않습니다.
- 데스크톱에서만 상승/하강 버튼을 플레이어 위쪽으로 소폭 올립니다.
- 모바일의 상승/하강 버튼 위치와 그 외 모든 UI 배치는 변경하지 않습니다.

검증 범위
- 변경한 TSX 5개 파일은 TypeScript transpile 구문 검사를 통과했습니다.
- 전체 프로젝트 tsc --noEmit 및 Next.js build는 이 실행 환경에 node_modules가 없어 실행하지 못했습니다. 설치 스크립트가 사용자 PC에서 전체 타입 검사와 프로덕션 빌드를 실행합니다.
- 실제 브라우저에서의 이동/줌 동작은 배포 후 사용자 PC와 휴대폰에서 확인해야 합니다.
