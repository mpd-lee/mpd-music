MPD MUSIC STUDIO WORLD V19 FINAL REFINEMENT

V19은 사용자가 제공한 현재 프로젝트 ZIP과 V18 적용 상태를 기준으로, 정면 해안 사진과 좌우·후면 숲 파노라마가 만나는 배경 연결부를 정리합니다. 기존 악기, 이동, 착석/눕기, 수영장 진입, 수중 월드, 채팅, 음악 플레이어 기능은 변경하지 않습니다.

1. 정면 해안 배경 평면과 숲 파노라마 원통의 높이 및 수직 중심을 같은 기준값으로 맞춰 위·아래 단차를 줄입니다.
2. 숲 파노라마의 개방 각도를 정면 해안 배경 양 끝의 시야각과 맞춰 좌우 연결 위치를 정렬합니다. 후면 개방부는 유지하며 좌우 가장자리 색상을 서로 같게 강제하지 않습니다.
3. 숲 사진의 왼쪽과 오른쪽 가장자리 색상 평균을 정면 해안 사진의 각각 대응하는 가장자리와 비교해, 바깥쪽 약 15.5% 구간에만 행 단위 색상 보정을 부드럽게 적용합니다. 중앙 숲 디테일은 그대로 유지합니다.
4. 기존 숲 사진의 녹색 톤 보정과 크롭 처리를 유지합니다. 이미지 처리는 텍스처 생성 시 한 번만 수행하고 프레임마다 픽셀을 다시 계산하지 않습니다. 모바일은 기존 모바일 이미지 자산을 사용하고, PC는 원본 자산 해상도 범위에서 처리합니다.
5. 현재 프로젝트에 이미 포함된 YouTube IFrame API 재시도 보완 코드는 그대로 보존하며, V19에서는 해당 파일을 덮어쓰지 않습니다.

적용 및 배포:
- 적용 스크립트는 변경 대상 파일을 Documents\MPD_Music_Studio_Backups\WORLD_V19_<timestamp>에 먼저 백업합니다.
- TypeScript 검사와 Next.js 프로덕션 빌드가 성공한 경우에만 Git commit/push와 Vercel Production 배포를 시도합니다.
- TypeScript 또는 프로덕션 빌드가 실패하면 V19 변경 파일을 백업본으로 복구합니다.
- GitHub 또는 Vercel 인증/권한 오류는 이미 빌드에 성공한 소스를 되돌리지 않습니다. 안내된 로그인 또는 권한 문제를 해결한 뒤 재시도할 수 있습니다.
- .env.local, Git 원격 설정, Supabase 데이터/정책은 수정하지 않습니다.

화질 참고:
정면 배경 원본은 1774x887, 숲 배경 원본은 1376x768입니다. V19은 소스 이미지를 네이티브 4K로 바꾸는 작업이 아니라, 기존 원본을 유지하면서 정렬·색상 연결·텍스처 필터링을 개선하는 작업입니다.
