MPD MUSIC STUDIO WORLD V38 - 하늘 천정 구름 보강 및 수중 이동 응답성 마무리

UI 보존
- app/globals.css, chat-panel.tsx, studio-app.tsx를 수정하지 않습니다.
- 모든 창/패널의 CSS 크기, 위치, 간격, 정렬을 그대로 둡니다.

하늘/숲
- 정면 해안 사진의 전체 상단 하늘 영역에서 흰 구름 픽셀만 추출해 equirectangular 하늘에 합성합니다.
- 기존 V37의 좁은 중앙 샘플 범위가 구름이 적은 파란 부분을 가져오던 문제를 수정했습니다.
- 푸른 하늘, 초록 잎, 갈색 가지는 합성에서 제외하며 알파 투명 구멍/천정 평균색 캡을 사용하지 않습니다.
- 숲/해안 원통은 기존의 지붕처럼 과도하게 높은 높이와 하늘을 너무 많이 드러낸 낮은 높이의 중간값으로 조정했습니다.

수중 배경
- V32 자연 산호초 파노라마 원본을 유지합니다.
- 중앙 햇빛 기둥의 밝은 픽셀만 공간 마스크로 더 낮추며 블러, 수평 픽셀 혼합은 하지 않습니다.
- 좌우 늘어진 가장자리는 기존 크롭으로 억제합니다.
- 근거리 산호 스트리밍 구역을 조금 더 촘촘히 배치해 실제 이동 시 전경 시차가 더 분명하도록 했습니다.
- 근거리 산호/암초는 약간 축소하되 다이버 모델 크기는 그대로 둡니다.

수중 이동
- 화면 탭/클릭 목적지 거리를 120~480m로 조정해 입력 후 이동이 즉시 눈에 들어오게 했습니다.
- 조이스틱 수평 속도 42m/s, 클릭 경로 속도 84m/s, 상승 25m/s, 하강 30m/s.
- 짧은 조이스틱 탭도 약 1.25초 전진 펄스를 발생시킵니다.
- 기존 100km x 100km 수평 탐험 범위와 최대 8km 수심을 유지합니다.
- 키보드는 물리 키 코드, 모바일은 Pointer Events, 클릭/터치는 캔버스 좌표에서 처리합니다.

카메라
- 수중 기본 FOV는 야외와 동일한 PC 50도/모바일 52도.
- 휠/핀치 줌은 FOV를 변경하므로 캐릭터와 360 배경이 함께 확대/축소됩니다.

검증
- 설치 스크립트가 사용자 PC에서 TypeScript 전체 검사와 Next.js 빌드를 수행합니다.
- 실제 브라우저 입력은 배포 후 확인해야 합니다.
