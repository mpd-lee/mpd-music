MPD MUSIC STUDIO WORLD V32

핵심 수정
1. 하늘 360도 배경의 하단 단색 파란색 문제를 피하도록 V29의 전체 하늘 이미지 기반 V32 파노라마로 교체하고 좌우 경계를 블렌딩했습니다.
2. 스튜디오 주변 가장 가까운 좌우 나무 줄을 약간 뒤로 이동하고 크기를 줄여 지붕 위 시야를 열면서 원거리 숲 배경은 유지했습니다.
3. 수중 파노라마의 과도한 하이라이트와 색 번짐을 낮춘 V32 자연 톤 에셋으로 교체하고 수중 조명 및 노출을 완화했습니다.
4. 수중 클릭 목적지의 최대 수평 이동과 깊이 변화를 제한해 도달할 수 없는 먼 목적지가 만들어지는 현상을 줄였습니다.
5. 클릭 수중 이동 구체의 양면 레이캐스트를 허용했습니다.
6. 기존 ±1250m 수평 범위와 약 600m 수심을 유지하고, 해당 범위를 덮는 실제 해저 지형을 추가했습니다.
7. 품질 설정에 따라 산호, 암초 바위, 해초 군집을 여러 위치와 깊이에 배치했습니다.
8. 수면 복귀 자동 전환 임계값을 실제 수면 높이 가까이로 조정했습니다.
9. 수중 카메라 시야를 조금 넓히고 최대 궤도 거리를 확장했습니다.
10. 수중 모드 전환 때 키보드/조이스틱/상승·하강 입력을 초기화해 눌림 상태가 남지 않도록 했습니다.
11. 채팅/방명록이 동시에 열리지 않도록 연결하고 채팅 패널의 CSS 클래스 누락을 수정했습니다.
12. 모바일 상단바, 메뉴, 채팅/방명록, 조이스틱, 상승·하강, 음악 플레이어를 viewport 기준으로 재배치했습니다.

보존
- 기존 스튜디오 룸, 음악 플레이어, 콘솔/스피커 플레이어, Global Chat, 1:1 채팅, 음성통화, 방명록, 운동기구 및 기존 환경설정 파일은 수정 대상에 포함하지 않았습니다.
- .env.local, .env 및 Vercel 비밀 설정을 변경하지 않습니다.

검증
- 패치 생성 시점에는 Windows 실기기 브라우저에서의 마우스/터치 UX와 Vercel Production을 직접 실행 검증하지 않았습니다. 배포 스크립트는 로컬 TypeScript 검사와 Next.js 빌드가 모두 성공한 경우에만 Git Push 및 Vercel Production 배포를 진행합니다.
