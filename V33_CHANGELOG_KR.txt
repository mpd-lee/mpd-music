MPD MUSIC STUDIO WORLD V33 변경 기록
====================================

[하늘 / 숲]
- V33 equirectangular 하늘 배경을 Scene.background에 적용해 천정까지 무한 배경으로 채웁니다.
- 숲과 정면 해안 파노라마의 원통 반경과 높이를 통일하고 이음부 겹침을 유지합니다.
- 숲 사진의 좌우 색상 보정, 상단/하단 짧은 페더, 디테일 샤프닝을 적용합니다.
- 배경 원통 반경을 늘려 숲/해안의 원근을 조금 더 멀게 보이도록 조정합니다.

[수중 배경 / 선명도]
- V33 수중 파노라마를 적용하고 좌우 연결부를 보정합니다.
- 파노라마 돔은 잠수부를 따라가며 유한 반경으로 렌더링되어 카메라 줌에 반응합니다.
- 실제 바닥 평면을 최대 수심에서도 파노라마 돔 아래에 위치시켜 사진과 바닥 평면이 교차하며 생기는 가로 경계/번짐을 방지합니다.
- 가짜 광선/원뿔 효과는 사용하지 않고 파노라마에 이미 포함된 자연광을 유지합니다.

[수중 이동]
- 캔버스에서 짧게 클릭/탭하면 현재 시야 방향으로 3D 목적지 수영을 시작합니다.
- 드래그는 OrbitControls 시야 회전, 두 손가락 제스처는 확대/축소로 유지합니다.
- 모바일 조이스틱과 PC WASD/방향키 수평 이동을 지원합니다.
- PC/모바일 상승·하강 버튼, Space/Shift/방향키 수직 이동을 지원합니다.
- 8km x 8km(좌우/전후 각 ±4km), 최대 약 900m 깊이까지 자유 이동 범위를 넓힙니다.
- 수중 이동 시 잠수부를 따라 카메라와 궤도 타깃을 함께 이동합니다.

[수중 생물]
- 열대어에 눈 소켓/홍채/동공/각막 반사광, 입, 아가미 덮개와 아가미 선, 비늘 범프 패턴을 추가합니다.
- 가오리와 상어에 눈과 아가미 선을 보강합니다.
- 바다거북 눈 디테일과 기존 지느러미 움직임을 유지합니다.
- 잠수부 주변 물고기 떼/거북/가오리/대형 생물의 동행을 유지해 넓은 이동에서도 생물의 존재감을 확보합니다.

[PC / 모바일 UI]
- PC 상승/하강 버튼을 음악 플레이어 위로 이동합니다.
- 모바일 상승/하강 버튼을 축소하고 조금 낮춥니다.
- 모바일 Global Chat 높이와 메시지 영역을 늘려 여러 줄이 보이게 합니다.
- 채팅/방명록/피아노 패널이 열리면 SCUBA 안내 HUD를 숨겨 입력 겹침을 완화합니다.
- 캔버스 터치 입력은 터치 조작/두 손가락 줌을 받을 수 있도록 유지합니다.

검증 주의
---------
- 이 패치 산출 환경에서는 변경 TS/TSX 파일의 문법 파싱을 확인했습니다.
- 실제 프로젝트 의존성 전체를 이용한 `tsc --noEmit`과 `next build`는 사용자 PC의 설치 스크립트에서 실행됩니다.
- 검사 실패 시 커밋 이전 변경 파일은 자동으로 기존 백업본으로 복원됩니다.
