MPD MUSIC STUDIO WORLD V34 - 수중 자유 이동 및 배경 마감

이 패치는 현재 안정 기준 V32 장면 소스를 다시 기반으로 배경/잠수 관련 5개 코드 파일만 교체합니다.
UI 창, 대화상자, 플레이어, 방명록, 글로벌 채팅의 크기/위치/배열 CSS는 변경하지 않습니다.
.env 및 .env.local은 읽거나 수정하지 않습니다.

1. 지상 배경
- ForestPanorama 사진 상단의 캐노피를 더 넓고 부드럽게 투명 페이드하여 진짜 하늘 파노라마가 비치도록 처리.
- 숲과 해안 원통의 반경/높이를 함께 늘려 수평선과 원거리 배경이 조금 더 멀게 보이도록 함.
- 기존 숲/해안의 좌우 색상 매칭과 페더링은 유지.

2. 수중 배경
- V32의 자연스러운 360도 산호초 사진을 사용하고 카메라 정면의 합성 광선이 덜 보이도록 배경 방향/밝기 조정.
- 절차적 바닥 텍스처의 인공 광선 패턴을 제거.
- 유한한 해저 평면은 화면에서 보이지 않는 클릭 감지면으로만 남겨 하단의 파란 직선/평면 가장자리를 제거.
- 배경은 360도 사진의 모래 바닥/산호가 보이도록 유지.

3. 자유 잠수 이동
- 수평 탐험 범위: X/Z 각 -2500m~+2500m.
- 수직 탐험 범위: 수면 아래 약 1500m까지.
- 마우스 클릭/모바일 화면 탭: 카메라 ray 기반 3D 목적지 이동.
- 조이스틱/WASD: 수평 자유 수영. 짧은 터치·조이스틱 이동도 누락되지 않도록 입력 변경을 즉시 전달.
- 상승/하강 버튼 및 키보드: 수직 수영. 버튼 누르는 동안 포인터 캡처를 유지해 손가락이 버튼 밖으로 나가도 입력 상태가 안정적으로 종료.
- 수중 전용 카메라 추적과 넓은 탐험 영역 적용.
- 마우스 휠과 스마트폰 두 손가락 핀치: 카메라 FOV를 조정하여 캐릭터와 배경이 함께 확대/축소.

4. 수중 생물
- 가까운 열대어에 홍채/동공/각막 하이라이트, 입술/입, 아가미 덮개와 곡선 아가미 선, 비늘 인스턴스를 추가.
- 먼 물고기 떼는 GPU 인스턴싱을 유지하여 모바일 부담을 제한.

검증 안내
- 패치 스크립트는 먼저 프로젝트 파일을 백업하고 TypeScript 및 Next.js 빌드를 실행합니다.
- 검사 실패 시 V34가 덮어쓴 7개 파일만 백업에서 되돌립니다.
- 실제 수중 터치/클릭/조이스틱/상승/하강/줌의 동작은 실제 기기에서 최종 확인이 필요합니다.


[V34 Hotfix 1 - 2026-11-27]
- TypeScript TS2367 오류 수정: FishScales의 yRows는 mobile=2, 그 외=3으로 1이 될 수 없으므로 불가능한 yRows===1 비교를 제거하고 분모를 Math.max(1, yRows - 1)로 보호했습니다.
- UI 창/패널의 CSS 크기·위치·배치는 변경하지 않았습니다.
